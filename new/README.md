# 底层实现：语言技术漫谈

这是第三次尝试把过去两年来的一些项目整理成技术书籍，这次我的目标只是完成，而不像过去那样有很多顾虑，想写出自己的特点，担心写的不好，以及始终怀疑做这些的意义。这次我想一天写一篇文章，就是把以前的内容重新编辑，以及再把代码也再整理下，争取这个暑假完成，除了UTF-8/Regex/Trie/CRF/W2V/LDA/BPE这些外，我会把Zero/Matx也加进来，本书的主旨就是要把训练语言模型的全部细节都尽量涵盖。吸取之前的教训，这次只能慢，不能快，完成当天的就不要冒进了，而且一个暑假呢，不要焦虑，享受写作，写成什么都可以。

本书的初衷是涵盖处理自然语言与编程语言的基础技术，通过底层实现的方式把机制搞清楚，搞明白，也会对某些现在模块提出些改进点，但不会涉及到具体训练模型，以及编译器部分也不会涉及到性能优化，只是更完善整个语言处理的技术栈而引入。
