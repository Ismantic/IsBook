# 底层实现：训练引擎

语言模型不仅是网络结构和训练算法，还依赖一套能够表示张量、记录计算图、传播梯度并执行算子的训练引擎。本书以我实现的 [Zero](https://github.com/Ismantic/Zero) 为基础，从底层数据结构出发，逐步说明一个小型深度学习框架如何完成模型训练。

Zero 使用 C++17 编写，同时支持 CPU 和 CUDA。它参考了 PyTorch 的动态图设计，但没有追求完整的框架功能，而是保留训练过程所需的核心部分。代码规模较小，可以把张量、自动微分、模型、优化器和 GPU kernel 放在同一个实现中观察。

## 内容结构

全书由七篇相对独立的文章组成：

- **自动微分**：从链式法则到动态图的构建与反向遍历。
- **张量与内存**：介绍形状、步长、存储共享和设备内存。
- **算子与反向传播**：说明算子执行、广播、矩阵乘法以及梯度计算。
- **模型与参数**：组织可训练参数，并组合 Linear、MLP 和 Dropout 等模块。
- **优化器**：实现梯度裁剪、ClippedSGD、AdamW 和学习率调度。
- **GPU 执行**：讨论 CUDA kernel、归约、内存池、cuBLAS 与设备派发。
- **GPT 训练**：将前面的组件组合起来，训练一个字符级 GPT。

这些文章按照依赖关系排列，适合顺序阅读；如果已经熟悉深度学习框架，也可以直接选择感兴趣的部分。书中重点解释实现背后的约束和数据流，完整代码与可运行示例以 Zero 仓库为准。

## 阅读范围

本书关注的是训练引擎怎样工作，而不是介绍深度学习的全部理论。公式用于说明实现，代码则用于展示公式如何落到张量形状、内存布局和算子接口上。读完以后，读者应该能够沿着一次训练迭代，理解数据从前向计算、损失函数和反向传播，直到参数更新与 GPU 执行的完整过程。
