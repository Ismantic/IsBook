# 是语指北录

《是语指北录》想做的事情，不是把若干项目说明文档简单装订成册，而是把它们重新组织成一条可以连续阅读的技术路径。

这条路径有一个很明确的主线：以 NLP 为中心，从文本最底层的编码问题出发，经过模式匹配、字典结构、分词、tokenizer、序列标注、词向量与主题模型，最后进入 GPT 与大模型实现。

换句话说，这本书关心的不是“某个单独模块怎么用”，而是：

- 文本在进入算法之前，最基本的表示问题是什么
- 词典、规则和统计模型各自解决了什么问题
- 传统 NLP 工具链是怎样一步步发展起来的
- 为什么今天很多问题最终会汇合到 GPT 这一路线上

## 本书结构

全书当前分为九章：

1. `Unicode`：Unicode、UTF-8 与文本处理基础
2. `Regex`：正则表达式与匹配模型
3. `Trie`：Trie、Critbit Trie、Double-Array Trie
4. `Cut`：基于词典与图搜索的中文分词
5. `Tokenizer`：BPE、BytePiece 与 tokenizer 训练
6. `CRF`：条件随机场与序列标注
7. `W2V`：Word2Vec 与词向量
8. `LDA`：LDA 与主题模型
9. `GPT`：自动微分、张量、模型与 GPT

## 适合怎样的读者

这本书更适合下面两类读者：

- 已经接触过 NLP 或深度学习工具，但希望把底层原理和工程结构重新串起来的人
- 会写代码、也能看 C++ 或 Python，但不满足于只会调用现成库的人

它不是一本“快速上手某个框架”的手册，也不是一本纯数学推导书。更准确地说，它试图站在系统实现和算法理解的交界处，把很多平时分散出现的知识重新串起来。
